# Bank Management System

A simple menu-driven Bank Management System developed using C.

## Features

* Create a bank account
* Deposit money
* Withdraw money
* Check account details
* Validate withdrawal amount
* Check insufficient balance
* Menu-driven interface

## Concepts Used

* C structures
* Functions
* Pointers
* Conditional statements
* Switch-case
* Loops
* User input/output

## How to Run

Compile:

```bash
gcc bank_management_system.c -o bank
```

Run:

```bash
./bank
```
